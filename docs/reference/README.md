# Reference

**Reference.** The exact syntax of the blocks, files and messages Outprint reads or shows.

Each page lists keys one by one. A key is a heading you can link to, with its
type, whether it is required, its default, what it does and an example.

| Page | What it lists |
|------|---------------|
| [Metadata Block](metadata-block.md) | The block at the top of a document: layering, types and the error list. |
| [Standard Fields](standard-fields.md) | Common field names that Templates reuse. |
| [Binding block](binding-block.md) | The block in a Collection description that chooses a Template and a Configuration. |
| [Template package](template-package.md) | The files of a Template and the keys of `manifest.yaml`. |
| [Template checks](template-checks.md) | Typed patterns, the drift guard, the TeX deny-list and path confinement. |
| [Configuration package](configuration-package.md) | The keys of `configuration.yaml`. |
| [Service configuration](service-configuration.md) | The keys of the file that names the packages and the allowed Bindings. |
| [Error messages](error-messages.md) | One entry for every message code. |
| [Limits](limits.md) | The size and time limits of a PDF. |
| [Settings](settings.md) | The environment variables that configure Outprint, with type and default. |
